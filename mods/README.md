# Projekt-specifikus játékmódosítások

Ez a könyvtár a saját feature-ek magas szintű terveinek, adatsémáinak és az
upstreamtől külön tartható kiegészítőinek helye. A tényleges engine- vagy klienskód
az rs-sdk architektúrájának feltérképezése után kerül a megfelelő helyre.

Első tervezett modul: `properties` (vásárolható ingatlanok).
