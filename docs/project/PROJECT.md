# Agent Society RS

Ez a fork a MaxBittker/rs-sdk működő bot-, SDK- és LostCity-alapjára épül.
A cél nem a hivatalos Old School RuneScape automatizálása, hanem egy saját,
helyben futó agent-társadalom és gazdasági szimuláció kialakítása.

## Tervezett rétegek

1. Stabil rs-sdk és helyi szerver baseline.
2. Több lépéses `agent-skills` könyvtár.
3. Diminishing XP és gazdasági újraegyensúlyozás.
4. Általános ingatlan- és tulajdonjogi rendszer.
5. Tartós agent-identitás, célok, kapcsolatok és memória.
6. Ritkán meghívott, magas szintű skillt választó LLM planner.
7. Multi-agent kereskedelem, vállalkozások, bankok és hitelek.
8. Új skillek és hosszabb termelési láncok.
