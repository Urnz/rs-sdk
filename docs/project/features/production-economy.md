# Új skillek és termelési gazdaság – távlati vázlat

A hosszú távú rendszer ne legyen mereven az eredeti RuneScape skillekhez kötve.
Egy általános agent tetszőleges `Skill[]` képességkészletet tanulhat.

Lehetséges irányok: engineering, machining, merchanting, accounting, banking,
management, medicine, law, logistics és politics.

Mintalánc:

`vasérc -> olvasztás -> acél -> öntés -> megmunkálás -> gépalkatrész -> gép -> gyár`

A cél, hogy a késztermék valódi termelőtőke legyen: növelje a későbbi kapacitást,
minőséget vagy hatékonyságot, ne csupán XP-t adó, értékvesztő köztes termék legyen.
